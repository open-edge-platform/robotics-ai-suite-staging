# AI Toolkits

The [AI Models Catalog](/models/) provides the models a robot runs; AI Frameworks are the
runtimes and toolkits that train, optimize, deploy, and serve those models on the development
kit. Each framework targets OpenVINO, so inference runs across the Intel CPU, GPU, and NPU
and integrates with the ROS 2 and control stack configured in the previous sections.

The section is organized by domain:

- **[Gen AI](./gen-ai/)** — serve large language models on the robot for natural-language
  command interpretation, task planning, and reasoning, offline and on-device.

- **[Vision AI](./vision-ai/)** — train, optimize, and run the perception models that let a
  robot detect objects, segment scenes, and inspect for defects.

- **[Physical AI](./physical-ai/)** — develop and run the robot-learning and embodied-AI
  policies that map perception to action.
