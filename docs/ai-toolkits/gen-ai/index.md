# Gen AI

## Introduction

Generative AI frameworks run large language models (LLMs) directly on the development kit. On
a robot, a local LLM interprets natural-language instructions, breaks high-level goals into
executable steps, and reasons over task context. Running on-device keeps response latency
bounded and keeps the robot operational without a network connection.

These frameworks serve models from the [AI Models Catalog](/models/), accelerated with
OpenVINO across the Intel CPU, GPU, and NPU.
