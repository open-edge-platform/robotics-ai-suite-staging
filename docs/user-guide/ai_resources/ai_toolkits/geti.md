# Geti

[Geti](https://github.com/open-edge-platform/geti) is an interactive computer-vision
platform for labeling data and training, optimizing, and exporting production-ready
vision models with minimal ML expertise.

It accelerates building the perception models a robot relies on — object detection,
segmentation, and anomaly or quality inspection — and exports them in OpenVINO-ready
formats for on-robot deployment.
