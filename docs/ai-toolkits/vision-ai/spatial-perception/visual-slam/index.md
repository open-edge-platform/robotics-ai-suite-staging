# Visual SLAM

Visual SLAM (Simultaneous Localization and Mapping) estimates the camera's pose while
building a map of the environment from the same image stream. The systems below differ in
how they represent the map, from sparse feature points to learned dense geometry to
Gaussian-splat radiance fields.

- [ORB-SLAM3](./orb-slam3)
- [DROID-SLAM](./droid-slam)
- [3DGS-SLAM](./3dgs-slam)
- [VGGT-SLAM](./vggt-slam)
