# IMU

Connect Inertial Measurement Units (IMUs) to process high-frequency motion data for dead reckoning and state estimation.

- **[Connect and Stream](connect-and-stream.md)**: Interface the IMU, load drivers, and read raw accelerometer and gyroscope data.

- **[Calibrate and Sync](calibrate-and-sync.md)**: Perform Allan Variance calibration and synchronize motion data timestamps with the visual pipeline.

- **[Hardware Reference](hardware-reference.md)**: Supported IMUs, mounting orientations, and noise characteristics.
