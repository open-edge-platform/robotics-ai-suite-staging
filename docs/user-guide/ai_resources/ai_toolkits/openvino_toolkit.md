# OpenVINO Toolkit

[OpenVINO](https://github.com/openvinotoolkit/openvino) is Intel's toolkit for
optimizing and deploying deep-learning inference. It imports models from common
frameworks and targets Intel CPUs, GPUs, and NPUs.

It provides the inference backbone for the Suite — run detection, segmentation, depth,
SLAM, and Vision-Language-Action models efficiently across the available Intel compute
on the robot.

OpenVINO is developed in the open. Explore the source, documentation, and installation
instructions:
