# Zenoh

zenoh unifies pub/sub, distributed queries, and storage in a single protocol built
for the edge-to-cloud path. It runs over constrained networks with low wire
overhead and routes between hosts and sites without a central broker, which suits
multi-robot and remote-monitoring setups that span beyond a single machine. See
the project at [zenoh.io](https://zenoh.io/).
