# IMX415

The Sony IMX415 is an approximately 8.5 MP (4K) sensor with strong low-light performance, suited to sharp general-purpose video capture.

| Property | Value |
|----------|-------|
| Type | 2D color, 4K, low-light |
| Vendor | Leopard Imaging |
| Interface | MIPI CSI-2 |
| IPU support | IPU6EPMTL |

## Quick start

Complete the [MIPI CSI-2 bring-up steps](index.md#bring-up-a-mipi-csi-2-camera), using the sensor-specific values below.

| Parameter | Value |
|-----------|-------|
| BIOS custom HID | `IMXSN415` |
| Link frequency | 445.5 MHz |
| Sensor I2C address | `0x1a` |
| MCLK | 23 MHz |
| Configuration files | `config/imx415/ipu6epmtl` |
| `icamerasrc` device name | `imx415-a` |
| Tested resolution / format | 3840×2160, NV12 |

Once the sensor is configured in BIOS and the configuration files are installed, preview the stream:

```bash
gst-launch-1.0 icamerasrc num-buffers=-1 scene-mode=auto device-name=imx415-a printfps=true io-mode=dma_mode ! 'video/x-raw(memory:DMABuf),drm-format=NV12,width=3840,height=2160' ! glimagesink sync=false
```
