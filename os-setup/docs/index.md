# Operating System

Install and configure a Linux operating system on a Robotics Development Kit after the
hardware has been brought up.

## Configuration guides

- [Supported OS](./supported-os) — Ubuntu, Yocto, and Zephyr.
- [Real-time Setup](./real-time-setup) — configure the real-time kernel, Intel TCC, and
  supported system tuning.
- [Time Synchronization](./real-time-setup/time-synchronization) — configure supported PTP capabilities on
  Intel platforms.

## Prerequisites

Complete the hardware bring-up for your kit before starting here. See
[Robotics Development Kits](../hardware/).
