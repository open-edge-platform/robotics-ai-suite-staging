# Introduction

The Intel® Robotics AI Suite is a full-stack platform for physical AI at the edge. One development kit, a real-time Linux kernel with Intel® TCC, ROS 2 middleware, PTP-synchronized sensor pipelines, EtherCAT and CAN motion control, and OpenVINO-powered AI toolkits for vision, generative, and embodied AI workloads, all running on CPU, GPU, and NPU in the same Intel® Core™ Ultra SoC.
