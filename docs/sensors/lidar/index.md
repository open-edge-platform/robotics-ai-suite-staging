# LiDAR

Connect LiDAR sensors to the development kit to ingest 3D point clouds for mapping and obstacle avoidance.

- **[Calibrate and Sync](calibrate-and-sync.md)**: Run extrinsic calibration against cameras and enable PTP timestamp synchronization.

- **[Hardware Reference](hardware-reference.md)**: Supported LiDAR models, networking specs, and recommended configurations.
