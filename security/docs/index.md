# Security

OS-level security features for a deployed robot. Apply them after the operating system,
drivers, and firmware are in place.

- [Secure Boot](./secure-boot.md) — verify the boot chain and sign custom kernel modules.
- [Disk Encryption](./disk-encryption.md) — protect data at rest with LUKS.
- [OS Hardening](./os-hardening.md) — reduce the attack surface and keep the system patched.
