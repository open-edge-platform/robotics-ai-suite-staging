# Real-time Setup
This section defines the supported sequence for configuring and validating real-time capabilities on Intel robotics platforms. Complete [Operating System](../index.md) for a supported [Robotics Development Kit](../../hardware/index.md) before starting.

1. Configure [Intel TCC](./intel-tcc/index.md).
2. Configure [real-time kernel](./real-time-kernel/index.md).
3. Apply [system tuning](./system-tuning/index.md).
4. Configure [Time Synchronization](./time-synchronization/index.md) (if using PTP)
