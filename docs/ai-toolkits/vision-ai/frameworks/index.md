# Frameworks

Vision frameworks and toolkits for building perception into a robot: training and fine-tuning
models, running inference, and assembling streaming pipelines. They target OpenVINO, so
perception runs across the Intel CPU, GPU, and NPU.

- [Geti Tune](./geti-tune)
- [Geti Anomalib](./geti-anomalib)
- [Geti Instant Learn](./geti-instant-learn)
- [DL Streamer](./dl-streamer)
- [Model API](./model-api)
- [Ultralytics](./ultralytics)
