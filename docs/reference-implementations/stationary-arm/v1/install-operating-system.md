# Step 2 — Install the operating system

Install Ubuntu 24.04 LTS with the Intel-validated drivers and firmware, then add the
OpenArm-specific software this build needs on top of it.

## In this blueprint

Standard Ubuntu 24.04 install, plus the OpenArm deployment software (SDK, SocketCAN tooling)
that the later steps depend on.

## Steps

- **Follow** — [Operating System](../../../os-setup/index.md) to install Ubuntu 24.04 LTS with drivers
  and firmware.
- **Done when** — the kit boots into Ubuntu 24.04 with the required drivers loaded.
