# Spatial Perception

Spatial Perception covers camera-based understanding of a scene's 3D structure and the
robot's pose within it. It includes visual SLAM systems that track pose while building a map,
as well as models that reconstruct scene geometry or maintain a persistent semantic memory
without running an online localization loop.
