# Physical AI

## Introduction

Physical AI frameworks develop and run the policies that map perception to action — the
control models behind robot learning, imitation learning, and embodied AI. They convert
trained policies to OpenVINO and run inference on-device, alongside the real-time control
loop, so a robot can execute learned behaviors such as manipulation and locomotion.
